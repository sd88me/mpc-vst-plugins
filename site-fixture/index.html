Get the install command

Needs SSH access as root to your device (a modded unit). Save your project first: the script asks before it stops MPC, installs everything you ticked, and starts MPC once.

Use the address as numbers and dots (or a host name): letters, digits, dots and hyphens only.

Paste this into a terminal (Terminal on Mac, PowerShell on Windows 10 or later)

Read the script first (recommended)

It is one plain shell script. Download it, read it, check its hash, then run it:

Open mpc-store.sh in your browser. It only installs what you name, checks each download against the checksum in the catalog, and never restarts MPC without asking.

Other commands

Same first part, different last word: list (what is available and installed), update (newer versions of what you installed with this script), remove <id>, prune (delete old backups of MPC's settings), sync (register plugin folders you copied into Synths by hand).
