MPC plugin installer

Install plugins from the catalog, or zips you already have, on your MPC or Force. This page runs on your computer only. Nothing about your device is saved.

1Connect to your device

Your device needs SSH access as root (a modded unit). Use the IP address shown on the device or in your router.

2Choose plugins

Tick what you want from the catalog, and/or drop plugin zips you downloaded or built yourself.

    4Remove plugins
    Show    
  
    The plugins on your device. Removing deletes the plugin's folder and its entry in MPC's plugin list (MPC's settings are backed up first). Your own files inside it, such as ROMs, kits and dumps, are kept. Addins (libraries MPC loads when it starts) are listed last: removing one runs its own uninstaller, which takes it out of MPC's start-up list and deletes its folder, settings included.
    
  
    • Connect to see what is on the device.
    
  
  
    
  
    

    

    


    

    
  
    5Register plugin folders
    Show    
  
    A plugin folder only shows up in MPC once it is in MPC's plugin list. Folders you copied in yourself, or that MPC forgot (for example because a card was out when MPC started), are not. This adds them, and drops entries whose plugin file is gone. Everything else in the list is left alone. MPC's settings are backed up first and MPC restarts once.
    
  
    • Connect to check.
    
  
  
    
  
    

    

    


    

    
  
    6Clean up old backups
    Show    
  
    Every install, removal and sync leaves a copy of MPC's settings file on the device. They are small, but they pile up. This keeps the newest ones and deletes the older ones. The newest backup is never deleted, and MPC is not restarted.
    
  
    Connect to see them.
    
  
    
  
    

    

    


    

    
  
    7Advanced: device patches
    Show    
  
    Not for most people. A patch changes the device itself (for example Akai's own MPC program), not a plugin. This list only looks: it asks the device which patches are applied and changes nothing. Applying or undoing a patch from this app is not available yet. To use one now, follow its guide and run its script yourself over SSH.
    
  
    
  
    Connect, then open this step to check.
