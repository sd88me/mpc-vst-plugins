MPC plugin installer

Install plugins from the catalog, or zips you already have, on your MPC or Force. This page runs on your computer only. Nothing about your device is saved.

Which one do I need?

  • Basic user: one-prompt install stick (MPC OS 3.9.1 and earlier only): the simplest. Pick this if you are on 3.9.1 or earlier.
    • Plug it in, confirm one prompt, and MPC restarts with the OpenMPC Plugin Manager VST installed. No network needed for the install.
  • Plugin manager stick (all MPC OS versions, including 3.10): browse and install plugins on the MPC's own screen. Pick this if you are on 3.10 or want the full catalog.
    • Nothing to set up on your MPC and no computer connection. Needs the MPC online (Wi-Fi or Ethernet).
  • For developers: SSH (turning it on from a stick: MPC OS 3.9.1 and earlier only): for modded units that already have root SSH, or to turn SSH on from a stick.
    • The Install over SSH tab installs plugins, addins, your own zips and patches from this computer, with remove, update and backup tools.

1Connect to your device

Your device needs SSH access as root (a modded unit). Use the IP address shown on the device or in your router.

Plugins and patches are community-provided and run as root on your device. Use them at your own risk, with no warranty: they can crash MPC, lose unsaved work or, at worst, leave the device needing a reinstall of its OS. Save your project and back up first. Not affiliated with or endorsed by Akai Professional.

Your own files inside it, such as ROMs, kits and dumps, are kept. Addins (libraries MPC loads when it starts) are listed last: removing one runs its own uninstaller, which takes it out of MPC's start-up list and deletes its folder, settings included.

      6Register plugin folders
      Show      
  
      A plugin folder only shows up in MPC once it is in MPC's plugin list. Folders you copied in yourself, or that MPC forgot (for example because a card was out when MPC started), are not. This adds them, and drops entries whose plugin file is gone. Everything else in the list is left alone. MPC's settings are backed up first and MPC restarts once.

      7Clean up old backups
      Show      
  
      Every install, removal and sync leaves a copy of MPC's settings file on the device. They are small, but they pile up. This keeps the newest ones and deletes the older ones. The newest backup is never deleted, and MPC is not restarted.

      8Advanced: device patches
      Show      
  
      Not for most people. A patch changes the device itself (for example Akai's own MPC program), not a plugin. If it goes wrong, MPC may not start until you Undo it or reinstall the OS. Checking only looks: it asks the device which patches are applied and changes nothing. Apply and Undo run the patch's own script on the device, with its default settings, and only after you type a confirmation word. Read the patch's guide first; one patch at a time; never as part of a plugin install. For options (such as which buttons to remap), run the script yourself over SSH as its guide says.

        For developers: turn on SSH (MPC OS 3.9.1 and earlier only)
        Show        

        
  
          
    
        • What this is for: developers who want an ordinary SSH login on their device, to install plugins and addins with this installer's SSH tab or by hand.
          • 
    
        • What the stick does:
      
            
        
          • Turns SSH on (a key you give, or a password).
            • 
        
          • Puts back any addins you already installed.
            • 
        
          • Optionally also opens the plugin manager, as in the section above (tick the box below). A stick holds only one autorun, so a stick that turns on SSH has to carry the manager itself if you want both.
            • 
      
          • 
    
        • How it works: MPC OS has its own stock "USB script" reader, built in by Akai (not a security hole). A stick with the right files on it makes MPC ask one on-screen question, then run a script as root. Nothing happens until you confirm that prompt on the device's own screen. The check the reader needs depends on your device's firmware, so this reads your own stock update image once (nothing from it is kept or sent anywhere).
          • 
    
        • Works on: Gen1 MPC (Live, One, X, Key), Force and Gen2 (Live III, One G2, Key(s) G2), but only on MPC OS up to 3.9.1.
      
          Akai closed this route in MPC OS 3.10. A stick built here will not work on a device already updated past that; the easy stick above is the only no-SSH option there.
          • 
    
        • Gen2 devices specifically: their storage can't be made to remember changes the way Gen1 and Force can, so SSH and the addins' settings are undone by every reboot. Reinsert the stick and confirm the prompt again after each restart.
          •

        A key is safer and is what to pick unless you know otherwise: it only adds a key on top of what is already

        Public key (goes on the stick): 
        
  
        
  
        
    
        Not recommended. A password can be guessed or intercepted; a key can't. This also turns on
    password login for root over SSH, where before only a key would have worked: anyone who learns this password gets a
    root shell on your device. Only works on a device whose root can be made writable (most Gen1/Force units).
    Gen2 needs a key (Live III, One G2, Key G2): their root is read-only, so a password can't be kept and the
    stick's SSH step fails.
