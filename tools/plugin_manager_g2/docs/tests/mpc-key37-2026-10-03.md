# Test report: MPC Key 37, 2026-10-03

TESTING.md run on an Akai MPC Key 37 (Gen1, MPC OS 3.9.1; az01 base 5.0.17, kernel 6.18 PREEMPT_RT). Community
SSH-enabled firmware, not MockbaMod: MPC's `LD_PRELOAD` carries a cursor library, a MIDI-inject library and the
usb-audio addin (installed by hand, so it shows **Old install**). Install target `/storage/Synths` (internal ext4,
25 GB); addins under `/data/mpc-addins`.

Build under test: this branch (addins + browser tile) built with the mpc-vst-plugins tooling from its PR #90
(tile + Default preset). The catalog was a copy of the live catalog with the two addin entries from mpc-vst-plugins
PR #144 added, served from the device itself (`file://`), since the live catalog has no addins until #144 merges.
Taps were injected over the network (the MPC Remote addin's standalone), the screenshots are the device's own
framebuffer; the table is what was seen.

| # | Do | Result |
|---|---|---|
| 1 | Open the plugin | **pass**: `17 plugins available · 0 updates available` in under 10 s; Chordsmith (installed) shows INSTALLED with its Tested badge |
| 2 | Tabs, filters, page arrows, tap cards | **pass**: DISCOVER 1/6, INSTALLED, UPDATES, All/Instruments/Effects/Addins (2 addins), page 2; tapped card gets the red outline; nothing cut |
| 3 | INSTALL Acid, APPLY | **pass**: INSTALL · QUEUED, `1 change queued: +Acid`, progress bar, then *Ready. Save your project: APPLY restarts MPC.* in amber |
| 4 | APPLY (RESTART & APPLY) | **pass**: MPC's pid changed within 3 s; Acid is in the plugin list (VST group) and loads with its skin (audio not checked) |
| 5 | Reopen the manager | **pass**: Acid shows INSTALLED with ⋮ |
| 6 | ⋮ REMOVE, APPLY twice | **pass**: REINSTALL / REMOVE under ⋮, REMOVE · QUEUED, `-Acid`, Ready, restart; Acid gone from the list, `MPC.settings` (backup `MPC.settings.bak-acid-<date>` written), the state file and `/storage/Synths` |
| 7 | Addins: INSTALL MPC Remote 0.2.1, APPLY twice; reopen, ⋮ REMOVE, APPLY twice | **pass**: `/data/mpc-addins/remote/` (manifest, .so, conf, uninstall.sh), `/etc/systemd/system/acvs.service.d/90-mpc-addins.conf` gained the .so, MPC's own `LD_PRELOAD` shows it after the restart and the addin answers on its port (a screen capture came back); after the removal the folder, the drop-in line and the port are gone and the card is back to INSTALL |

Also seen:
- The browser tile (`vst/art/tile.png`) shows in the INSTRUMENTS browser; tapping it lists the Default preset, and
  the preset opens the manager on the track. MPC indexes presets at start, so a freshly installed tile does nothing
  until the next restart (the install's own restart covers it).
- `device.txt` is written when the manager opens, so after a removal it still lists the removed plugin until the
  manager is reopened.
- Addins are not in `.pluginmgr-installed`: the installed scan reads each `addin.manifest` instead.

No red banner; `problem: none`. The fake device `tests/devices/mpc-key37.sh` recreates this layout for `tests/run.sh`.
